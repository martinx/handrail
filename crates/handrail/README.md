# handrail

Policy packs for coding agents — enforced where the agent allows it, honest where it doesn't.

**0.0.x is an early preview.** The binary only reports its version and where to start; it
changes nothing on your machine. The working installer for Claude Code is the POSIX-sh
prototype in the [repository](https://github.com/martinx/handrail). The Rust CLI replaces it
in milestone M1.

Unofficial project; not affiliated with Anthropic or any agent vendor. Licensed under Apache-2.0.
