# handrail

Policy packs for coding agents — enforced where the agent allows it, honest where it doesn't.

This crate is the `handrail` command-line tool. It currently targets Claude Code on macOS and
Linux: it installs security and privacy packs into Claude Code's root-owned managed policy
directory, so an agent running as you cannot change or disable them.

See the [repository](https://github.com/martinx/handrail) for documentation.
